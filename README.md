# Cylinder Net — GitHub Pages

פרויקט סטטי להצגת מודל OBJ/MTL בדפדפן באמצעות Three.js.

## העלאה ל-GitHub

1. צור Repository חדש ב-GitHub.
2. העלה את כל הקבצים והתיקיות מתוך הפרויקט לשורש ה-Repository.
3. עבור ל-Settings → Pages.
4. תחת Build and deployment בחר Deploy from a branch.
5. בחר branch בשם `main` ותיקייה `/ (root)`.
6. שמור.

לאחר זמן קצר האתר יהיה זמין בכתובת:

`https://USERNAME.github.io/REPOSITORY/`

## קבצים

- `index.html` — עמוד התצוגה
- `style.css` — עיצוב
- `app.js` — טעינת המודל ושליטה בתצוגת תלת־ממד
- `models/cylinder-net.obj`
- `models/cylinder-net.mtl`

> חשוב: פתיחה ישירה של `index.html` מהמחשב עלולה להיחסם בגלל מגבלות דפדפן. מומלץ לבדוק דרך GitHub Pages או שרת מקומי.
